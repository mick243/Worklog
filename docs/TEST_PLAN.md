## 읽는 법

- **상태**: 시나리오가 확인하는 상태예요.
  - 정상: 평소 쓰는 흐름이에요.
  - 비어 있음: 재료가 없거나 처음 쓰는 경우예요.
  - 잘못된 입력: 옵션·설정·답을 잘못 준 경우예요.
  - 극단적인 경우: 규모가 크거나, 중간에 끊기거나, 드문 상황이에요.
- **우선**: 타깃 사용자(나 또는 공개 도구를 설치한 다른 Claude Code 사용자)가 얼마나 자주 할 행동인지예요.
  - 높음: 매일 또는 매번 하는 행동이에요(일지 만들기, 화면 보기, 공개 전 검사).
  - 중간: 가끔 하는 행동이에요(패턴 추가, 다시 가리기, 옵션 바꾸기).
  - 낮음: 드물거나 사고에 가까운 상황이에요.
- **통과 기준**: 한 줄로 적었어요. PRD에 동작이 정해지지 않은 곳은 "(기대 동작)"을 붙였어요. 실제로 어떻게 동작하는지 먼저 확인해야 해요.
- **자동 시험**: 지금 `app/test/`의 시험 제목과 대조한 결과예요. 이번에 시험을 돌려 보지는 않았어요.
  - 있음: 같은 내용을 확인하는 자동 시험이 있어요.
  - 일부: 비슷한 시험은 있지만 이 시나리오 전체를 덮지는 않아요.
  - 없음: 자동 시험이 없어서 손으로 확인하거나 새 시험을 만들어야 해요.

## 준비

- 시험은 임시 데이터 폴더(`--data-dir`)와 가짜 세션 기록 폴더(`--claude-dir`)로 해요. 가짜 기록과 임시 git 저장소는 기존 시험 도우미(`app/test/helpers.ts`)로 만들 수 있어요.
- **실제 기록**이라고 적은 시나리오는 사용자의 실제 `~/.claude/projects`를 읽어요. 실행할 때마다 사용자 허락을 받고, 임시 데이터 폴더를 쓴 뒤 지워요.
- **수동**이라고 적은 시나리오는 실제 터미널 창이나 브라우저로 사람이 직접 봐야 해요.
