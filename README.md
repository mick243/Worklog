# 에이전트 팀 프로젝트 틀

기획 · 디자인 · 개발 · 취합 서브 에이전트 4개로 프로젝트 하나를 만드는 틀이에요. 아직 주제는 비어 있어요.

## 흐름

```
기획(planner) ──확정──┬─▶ 디자인(designer) ─┐
                      │                     ├─▶ 취합(integrator) ─▶ 차이 목록 ─▶ 고칠 쪽 다시 실행
                      └─▶ 개발(developer)  ─┘   (결과가 나올 때마다)
```

- 기획이 끝나고 사용자가 확정하기 전에는 다른 에이전트가 시작하지 않아요.
- 디자인과 개발은 동시에 돌아요. 개발은 디자인 없이 기능과 구조부터 만들어요.
- 취합은 디자인이나 개발이 끝날 때마다 돌아요. 개발이 아직 도는 중이면 코드는 건드리지 않고 비교만 해요.

진행 규칙의 원본은 [CLAUDE.md](CLAUDE.md)예요. Claude Code가 이 폴더에서 열리면 자동으로 읽어요.

## 시작하기

1. (선택) 이 폴더를 복사해서 프로젝트 이름으로 바꿔요. 틀을 다음에도 쓰려면 복사본에서 시작하세요.
2. 이 폴더를 작업 폴더로 Claude Code를 열어요.
3. 첫 메시지를 보내요.

   ```
   나는 [프로젝트 한 줄 설명]을 만들 거야. 기획 에이전트로 기획서부터 만들어 줘.
   ```

4. `docs/PRD.md`를 확인하고 고칠 점을 말하거나 "확정"이라고 해요.
5. "디자인이랑 개발 시작해 줘"라고 하면 둘이 동시에 돌고, 결과가 나올 때마다 취합 에이전트가 PRD와 다른 부분을 표로 알려 줘요.

## 폴더 구조

```
.claude/agents/
  planner.md      기획 에이전트
  designer.md     디자인 에이전트
  developer.md    개발 에이전트
  integrator.md   취합 에이전트
docs/
  PRD.md          기획서 (planner)
  DESIGN.md       디자인 문서 (designer)
  DEV.md          개발 메모 (developer)
  INTEGRATION.md  취합 기록과 차이 목록 (integrator)
app/              결과물 코드 (developer가 처음 실행할 때 만들어져요)
CLAUDE.md         메인 세션 진행 규칙
```

## 문서 상태 값

| 문서 | 상태 |
|---|---|
| PRD.md | 미작성 → 초안 → 확정 |
| DESIGN.md | 미작성 → 작성됨 |

## 기본값 (바꿔도 돼요)

- 개발 스택: PRD "기술 메모"가 비어 있으면 Vite + React + TypeScript
- 스타일: 색·글꼴·간격은 `app/src/styles/tokens.css`의 CSS 변수로만 써서, 취합 에이전트가 디자인 토큰 값만 바꿔 반영해요.
- 모델: 네 에이전트 모두 메인 세션과 같은 모델 (`model: inherit`)
